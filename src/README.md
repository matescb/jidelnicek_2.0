# Source Code Directory

This directory contains all the source code for the Jídelníček 2.0 application.

## Structure

- **auth/** - Authentication and authorization services
- **recipe/** - Recipe management functionality
- **trip/** - Trip planning and management features
- **sharing/** - Recipe marketplace and sharing capabilities
- **common/** - Shared utilities, helpers, and common components

Each service follows a modular structure with its own models, views, controllers, and utilities.
